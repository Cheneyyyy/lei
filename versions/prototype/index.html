LEARN · 01

先建立粵拼基本規則

先看規則，再用字卡和短句把聲音、漢字與拼音連起來。按小喇叭可以嘗試播放粵語讀音。

聲母

音節開頭的音。按例字旁的小喇叭，先聽完整音節，再留意開頭。

韻母

音節後面的主要音。例：gw + aa + n = gwaan。

六個聲調

粵拼用 1–6 表示聲調。用例字聽辨，比死記單音節更容易。
